# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be constructive, assume good faith, and critique code and ideas rather than
people. Harassment and personal attacks aren't tolerated.

Report unacceptable behaviour by opening a private security advisory on this repository or by
contacting the maintainers directly. Reports are handled confidentially.

The jokes in this repository are about software. Keep them that way.
